## Installation

```npm
npx shadcn@latest add @audiocn/quick-audio-popover
```

## What it does

The trigger shows the microphone state and a small live
[bar visualizer](/docs/components/bar-visualizer). The popover holds the
microphone select, on/off and mute buttons, and a system audio switch. Children
go at the bottom, for a link to full settings.
