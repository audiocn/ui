## Installation

```npm
npx shadcn@latest add @audiocn/vu-meter
```

## Usage

```tsx
import { VuMeter } from "@/components/ui/vu-meter";
```

```tsx
<VuMeter aria-label="Program level" input={sound.output} />
```

With no children, `VuMeter` renders the face, the scale, the needle and a "VU" legend. It fills the width of its container and keeps its shape; size it with a class such as `max-w-md`.

The needle moves like a real VU meter. It reads the audio itself, on the audio thread, every sample: it reaches 99% of a new level in about 340 ms, swings about 1% past it and settles. At silence it rests against the pin left of the scale. A level above +3 VU drives it against the right pin, where it bounces and comes to rest; the harder it hits, the further it bounces.

## Anatomy

```tsx
<VuMeter>
  <VuMeterFace>
    <VuMeterScale />
    <VuMeterNeedle />
    <VuMeterBadge />
    <VuMeterLegend />
    <VuMeterLabel />
  </VuMeterFace>
</VuMeter>
```

Every part is an element of its own, layered inside the face. `VuMeterScale` and `VuMeterNeedle` each draw an SVG with a 200 × 100 view box. With the default bottom pivot, `VuMeterBadge` sits below the scale and the needle passes over it, like a logo printed on the face. With `pivot="top"`, it sits at the top and covers the needle's end.

## Examples

### Pivot

Most VU meters pivot from below: the needle rises from under a lip in the bezel and the scale arcs over it. Set `pivot="top"` for a needle that hangs from above the window and swings over an upturned scale.

<ComponentPreview name="vu-meter-pivot" />

### Stereo

One meter shows one channel. Set `channel` on a pair of meters for left and right. With the default `"max"`, the needle follows the louder channel. The sample here is mono, panned left.

<ComponentPreview name="vu-meter-stereo" />

### Calibration

A VU meter reads relative to a reference level. `referenceDb` is the RMS level in dBFS that reads 0 VU: −18 by default (EBU R68), −20 for SMPTE. A sine at that level settles on 0 VU. Each meter below gets the same sound.

<ComponentPreview name="vu-meter-calibration" />

`minDb` and `maxDb` set the printed scale, in VU. For the broadcast scale, set `minDb={-20}` and add −20 to `ticks`.

### Variants

`classic` is a backlit face in a dark bezel and looks the same in light and dark themes. `flat` uses the theme's tokens. Set `--vu-face` and `--vu-face-shade` for a warm lamp.

## Input

`input` takes an `AudioNode`, an `HTMLMediaElement` or a `MediaStream`, such as the output of [useSound](/docs/hooks/use-sound) or a microphone stream. The meter taps it with a silent `AudioWorklet` and does not change what you hear.

```tsx
const sound = useSound("/sounds/peon-work-work-loop.wav", { loop: true });
<VuMeter input={sound.output} />;

const microphone = useMicrophone();
<VuMeter input={microphone.stream} />;
```

Without `input`, the needle stays where `--vu-level` puts it, so a static meter needs only CSS. Set `aria-valuenow` to the same reading, in VU:

```tsx
<VuMeter aria-valuenow={0} style={{ "--vu-level": 0.62 } as CSSProperties} />
```

`useVuNeedle(input, onPosition, options)` runs the same needle without the face, for a meter of your own. `onPosition` gets the scale position several times a frame, outside React.

## Scale law

A VU needle swings in proportion to the signal's amplitude, so the scale isn't linear in dB: −10 to −7 is squeezed at the left, and 0 VU sits about 62% of the way across. The same law is available as `vuTaper`, and as `taper="vu"` on [Level Meter](/docs/components/level-meter) and [dB Scale](/docs/components/db-scale).

The needle's movement is in `lib/audio/needle.ts`. The rectified signal (`|x|`) goes through one resonant 2nd-order low-pass: `lowPassCutoffHz` sets the speed, and `lowPassQ` the overshoot (0.5 never overshoots). The filter runs as a mass on a spring, so the pins act on the needle's speed: at the right pin it bounces back with `rebound` of its speed, and at the left pin it stops.

## Theming

| Variable or attribute | On | Meaning |
| --- | --- | --- |
| `--vu-face`, `--vu-face-shade` | root | The backlight, at the centre and the corners |
| `--vu-ink` | root | Scale and text |
| `--vu-needle` | root | Needle |
| `--vu-bezel` | root | Frame |
| `--vu-zone-ok`, `--vu-zone-warn`, `--vu-zone-clip` | root | Zone colours. `ok` is `--vu-ink`, as a VU scale prints its normal range in ink. `warn` is `--meter-warn`. `clip` is `--meter-clip` on `flat`, and a fixed red on `classic`, so it reads the same on the lit face in both themes |
| `--vu-level` | root, live | The needle's position: 0 at the left end of the scale, 1 at the right, and −0.04 to 1.04 against the pins |

| Data attribute | On | Meaning |
| --- | --- | --- |
| `data-variant` | root | `classic` or `flat` |
| `data-pivot` | root, scale, needle | `bottom` or `top` |
| `data-zone` | root, ticks, numbers, arcs | `ok`, `warn` or `clip`; on the root, where the needle points |
| `data-active` | root | The needle has left the rest pin |
| `data-pinned` | root | The needle is against the right pin |
| `data-status` | root | `idle` (no input), `loading`, `running`, `suspended` (the audio context waits for a click) or `error` (the audio thread could not start or stopped) |
| `data-major` | ticks | A numbered tick |
| `data-slot="vu-meter-cover"` | needle | The bezel lip over a bottom pivot. Hide it with `[&_[data-slot=vu-meter-cover]]:hidden` |
| `data-dimmed` | root | Inside a muted or silenced channel strip |

Text in the corners is sized in container units (`cqw`), so a small meter and a large one look the same. Size your own badge content the same way.

## Accessibility

- The root has `role="meter"` with `aria-valuemin`, `aria-valuemax` and `aria-valuenow` in VU, and `aria-valuetext` such as "−3.0 VU". These update at most four times a second.
- Give every meter a name with `aria-label` or `aria-labelledby`, including the channel for a stereo pair.
- The scale, needle and badge are hidden from assistive technology.
- With reduced motion, the needle moves to the current position four times a second instead of swinging.
