---
title: useLevel
description: Read a meter source into React state at a low rate, for labels and conditional UI.
---

Meters paint every frame without React. When you need the level in React, for
a label or to show a warning, `useLevel` samples the source a few times a
second.

```npm
npx shadcn@latest add @audiocn/use-level
```

## Usage

```tsx
const { peakDb, zone } = useLevel(analyser.meter);

return zone === "clip" ? <p>Turn your microphone down.</p> : null;
```
