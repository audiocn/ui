# audiocn logo

Browser and Apple icons use a white background so the dial stays visible on light and dark system surfaces.

The approved mark is a solid black rotary dial with one white rounded pointer. `logo.png` is the transparent master used by the site and social preview. The site inverts the mark in dark mode for contrast.

Run `pnpm brand:build` to regenerate the 16/32/48px favicon, 64px browser icon, and 180px Apple touch icon from this master. The normal build runs this too.

The master was prepared with the built-in image generation tool from the selected solid-dial concept. Asset preparation prompt:

> Use case: background-extraction. Edit target: the selected solid black circular audio knob logo in the provided image. Prepare THIS EXACT approved mark as a production logo asset. Remove the white canvas/background outside the black circular dial and make it genuinely transparent. Preserve the solid near-black circle and its white rounded diagonal indicator exactly: same silhouette, same relative position, thickness, angle, round ends and proportions. Keep the indicator white and opaque; it is part of the logo, not background to remove. Tight square framing around the complete dial with approximately 4 percent transparent margin on each side, centered. This is faithful asset preparation, not redesign. No new elements, rings, ticks, outlines, text or shadows. Preserve the smooth original edges and the original mark's geometry.
